# CDL 2026 hands-on guide: an evidence-first knowledge map

Step-by-step guide to the hands-on exercises of the Connected Data London 2026 master class
"Building Evidence-First Knowledge Graphs with Dynamic Ontology and Just-in-Time Entity Resolution"
(Weidong Yang, Kineviz; Mengjia Kang).

Read it as a web page: https://kineviz.github.io/CDL2026-sec10k-exercise-guide/

The exercises run in the Kineviz project CDL2026_SEC10K (notebook `CDL Exercises.md`), built from
2,068 SEC 10-K filings by 438 companies (2021-2025).
